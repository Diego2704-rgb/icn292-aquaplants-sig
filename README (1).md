# assets

Diagramas exportados del proyecto. Cada imagen se explica en el documento de `docs/` que la
referencia; esta carpeta guarda el archivo, no la explicación.

| Archivo | Qué es | Documento que lo explica |
| --- | --- | --- |
| `bpmn-as-is.png` | Proceso crítico actual en BPMN 2.0 | `docs/02-bpmn.md` |
| `bpmn-to-be.png` | Proceso crítico con la intervención del SIG | `docs/02-bpmn.md` |
| `er-preliminar.png` | Modelo entidad-relación preliminar | `docs/03-er-preliminar.md` |
| `*.bpmn` | Fuentes editables de los diagramas BPMN | — |

Convención: PNG a resolución legible (ancho mínimo 1600 px), nombre en minúsculas y con guiones,
sin espacios ni tildes.
